**Sajian! — Warung Rush** is a top-down cooking game that runs in a desktop browser from static files — no build step, no network, no libraries. Run a warung stall: tickets pin to the cork rail with patience bars, and you work the route — ingredient crates, chopping boards, a grill and fryer whose food burns if you dawdle, a plating counter for half-built plates, and the serving hatch where only an exact recipe match pays. Price plus a patience-scaled tip, combo multipliers up to ×3, three stars to keep, and a 150-second day that gets harder every day you survive.

**Controls:** WASD / arrows move · E interact (mash to chop) · mouse for menus · M mute.
